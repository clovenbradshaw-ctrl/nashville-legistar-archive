What this all means — the ledger / glossary
Pulled (all-time)
every contract ever accounted for — archived + currently staged, including earlier sessions' work.
Uploaded to archive.org
the durable originals (PDF + text) that now live forever on archive.org.
Staged now
pulled on the VM but waiting on the rate-limited archive.org drain.
Small files on GitHub
extracted text + reads + ledgers stored in this repo and queryable from this site.
Enumeration gaps
a department's search hit the portal's 1,000-row cap, so it can't be called complete yet — the deep lane subdivides (party → description → contract #) to measure past it.
Missing (recount)
tokens a fresh search shows that we don't hold yet — concrete, fetchable misses; a lower bound, never a guess.
Completeness verdicts
complete / incomplete / contested / unexamined (= not crawled yet — never counted as a pass). Colors: green / red / amber / gray.
Falsifying control
the exact condition that would prove a verdict, gap, or learned rule wrong — everything we assert carries one; an assertion with no control is refused.
QC grades
ok / suspicious / defect. A defect is a real problem surfaced (e.g. no durable home). "Exit 1" was a verdict, not a crash — QC now completes clean.
Rules learned / conceded
recurring failures become derived rules with a half-life; the proteasome concedes rules that outlived their evidence.
Roundups
period counts (24h / 7d / 30d) split by department and vendor — what was pulled and archived, from which agencies and who the vendors are.
Oversight / heal
self-healing actions: restarted daemons, re-armed timers, fetch paused/resumed on disk pressure, stagnation detected — each with a falsifying control.
Oversize routing
files over 20MB are routed to archive.org instead of GitHub; the repo is capped at 1.4GB — the data-budget guard.
